## 1. Aim of the Session
To design and implement materialized views and compare their performance with simple and complex views, thereby understanding their role in query optimization and improving system performance.

---

## 2. Software Requirements
- Database Management System: PostgreSQL / Oracle Database  
- Database Administration Tool: pgAdmin / Oracle SQL Developer  

---

## 3. Objectives
- To create simple views, complex views, and materialized views  
- To analyze execution time differences between different types of views  
- To understand performance benefits of materialized views in databases  

---

## 4. Procedure of the Experiment
- 1. Create tables Employee and Department with required fields  
- 2. Insert sample data into both tables  
- 3. Display table data using SELECT statements  
- 4. Create a simple view using a single table  
- 5. Execute the simple view and observe output  
- 6. Create a complex view using JOIN and aggregation functions  
- 7. Execute the complex view and analyze output  
- 8. Create a materialized view to store computed results  
- 9. Execute the materialized view  
- 10. Refresh the materialized view using REFRESH command  
- 11. Use EXPLAIN ANALYZE to check performance of each view  
- 12. Compare execution time of simple, complex, and materialized views  
- 13. Analyze results and draw conclusions  

---

## 5. Practical / Experiment Steps
Create SQL queries to:
- Create and use simple view  
- Create and use complex view with JOIN and aggregation  
- Create and refresh materialized view  
- Analyze performance using EXPLAIN ANALYZE
